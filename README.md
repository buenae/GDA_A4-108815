## Introduction to Pandas DataFrames – Replicating an article in Markdown

In dieser Aufgabe ging es darum zu verstehen, wie man mit GitHub und Jupyter-Notebooks umgeht, in dem man ein Repository erstellt und verwaltet. Ausserdem musste man mit den erlernten Markdown-Kenntnissen einen Artikel nachbilden.

**Liste der involvierten Dateien**
| Datei | Typ | Bedeutung |
| :--- | :--- | :--- |
| `Pandas.ipynb` | Jupyter Notebook |Datei, die in Jupyter Notebook erstellt und modifiziert wurde. Sie enthält den nachgebildeten Artikel. |
| `Pandas.webp` | Bilddatei (WebP) |Das im Artikel eingebettete Bild, welches sowohl im Hauptordner des Repositorys liegt, wie auch im `dist`-Ordner, um eine korrekte Darstellung der jeweiligen Dateien zu gewährleisten |
| `dist/Pandas.html` | HTML-Datei | Export aus dem Jupyter-Notebook, mit ausgeführten Code-Zellen. Kann in jedem Webbrowser angeschaut werden. |
